# Financial Summary Dashboard – Power BI
# Project Overview

This project presents a Financial Summary Dashboard developed using Power BI Desktop. The dashboard provides a comprehensive overview of key financial metrics, enabling stakeholders to monitor business performance and make informed decisions.

The report focuses on cost analysis, revenue performance, and product profitability across different segments, countries, and time periods.

# Project Objectives

Provide a high-level financial performance summary

Analyze sales and profitability by product

Monitor Cost of Goods Sold (COGS)

Enable interactive filtering for deeper insights

Support data-driven decision-making processes

# Key Performance Indicators (KPIs)

The dashboard highlights three primary KPIs:

Cost of Goods Sold (COGS): 101.83M

Total Profit: 16.89M

Total Products Sold: 1M

These KPIs provide an immediate snapshot of overall financial performance.

# Visualizations and Insights
# 1. Quantity Sold per Product (Line Chart)

Displays total units sold by product.

Enables trend comparison across products.

Identifies high-demand products.

# 2. Gross Sales by Product (Column Chart)

Shows total revenue generated by each product.

Facilitates product performance comparison.

Highlights top revenue-generating products.

# 3. Cost of Goods Sold by Product (Horizontal Bar Chart)

Illustrates production and procurement costs per product.

Supports cost analysis and expense monitoring.

Assists in evaluating profit margins.

# 4. Profit by Product (Donut Chart)

Presents profit contribution by product.

Displays percentage share of total profit.

Identifies the most profitable product lines.

# 5. Interactive Filters (Slicers)

The dashboard includes dynamic slicers to enhance user interactivity:

Segment Name

Country Name

Month

Year

All visuals update automatically based on selected filters, allowing users to perform flexible and detailed analysis.
